One binary. One command. Done.

prinstall is a single executable. No installer, no .NET runtime, no dependencies, no "please restart your computer." You point it at an IP address and it handles the rest — scans the printer, identifies the model, finds the right vendor driver, downloads it, stages it, and installs the printer.

Not "Generic / Text Only." Not "HP Universal 6 years old." The actual vendor driver, matched by hardware ID, verified before install.

It walks a six-tier cascade — local driver store, bundled packs, manufacturer download, Microsoft Update Catalog, SDI Origin driver packs, and IPP Class Driver fallback — and it will not give up before you do. If one source fails, it tries the next. Then the next. Then the next.

It finds your printers

Scans your whole subnet in seconds. SNMP, IPP, port probes — throws everything at the wall in parallel. That printer hiding in the corner with SNMP disabled? Found it. The USB printer Karen plugged in that Windows decided to install with "Generic / Text Only"? Found that too.

Scorched earth removal

Queue? Gone. Driver? Gone. Port? Gone. That ghost printer from 2019 that still shows up in Print Server Properties? Obliterated.

The print spooler can finally breathe. No orphaned ports, no dead drivers, no "the driver is in use by another printer" bullshit. One command and the machine is clean.

Script it and forget it

Pipe --json into your RMM. Deploy to 200 machines at 2 AM. Wake up to zero printer tickets. That's the dream. That's the whole point.

Remember HRESULT 0x80070705? We decode that garbage into actual English. Because Microsoft sure as hell wasn't going to.

Get it

Drop it anywhere and run it:

iwr https://github.com/limehawk/prinstall/releases/latest/download/prinstall.exe -OutFile prinstall.exe

Or install to PATH with the bootstrap script:

iwr -useb https://raw.githubusercontent.com/limehawk/prinstall/main/scripts/prinstall_setup.ps1 | iex

Then add a printer:

.\prinstall.exe add 192.168.1.47

Stop fighting printers.
