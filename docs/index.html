The problem is familiar.

New office. Twelve printers across three floors. You open Devices and Printers and start the wizard. It asks for a port. Then a driver. You pick "HP LaserJet" from a list that hasn't been updated since Windows 7. The test page comes out garbled. You go to HP's website and download a 200 MB "setup utility" that installs seventeen background services and a supply ordering app. The printer still doesn't work.

This happens every day, on every site visit, to every MSP tech in the field. I got tired of it, so I wrote prinstall.

What it does.

You run prinstall add 10.10.20.16. It probes the printer via SNMP and IPP, figures out the make and model, then walks a six-tier driver cascade looking for the best match. Local driver store first. Bundled packs. Manufacturer URLs. The Microsoft Update Catalog. SDI Origin driver packs. And if nothing else works, the built-in IPP Class Driver as a last resort.

Every driver is matched by hardware ID and verified before install. The INF is parsed, the HWID is confirmed, the .cat Authenticode signature is checked against Microsoft's certificate chain. Unsigned or tampered packs get skipped.

Removal is the same story. prinstall remove deletes the queue, checks if any other printer uses the driver, checks if any other printer uses the port, and cleans up whatever is orphaned. One command, no ghosts left behind.

Built for the field.

Every command takes --json so you can pipe output to your RMM. Every error is decoded — PowerShell's verbose noise is stripped, HRESULT codes are translated to English. It runs headless through SuperOps, ConnectWise, Datto, anywhere you can drop a binary.

USB printers are handled too. Windows loves to install them with "Generic / Text Only" and call it a day. prinstall add "HP LaserJet 1320" --usb swaps the driver on the existing queue without recreating it.

Get it.

It's a single .exe. No installer, no runtime, no dependencies.

iwr https://github.com/limehawk/prinstall/releases/latest/download/prinstall.exe -OutFile prinstall.exe

Or use the bootstrap script to install to PATH:

iwr -useb https://raw.githubusercontent.com/limehawk/prinstall/main/scripts/prinstall_setup.ps1 | iex

Then:

.\prinstall.exe add 192.168.1.47

Stop fighting printers.
