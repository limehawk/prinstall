Global flags

These work on everything. --json gives you machine-readable output you can pipe to jq or your RMM. --verbose breaks the install into a structured report — discovery phase, resolution phase, install phase — so you can see exactly what happened and why. --force skips safety checks when you know what you're doing.

prinstall add 10.10.20.16 --json          # pipe to jq or your RMM
prinstall add 10.10.20.16 --verbose       # structured install report
prinstall scan --community secret123      # custom SNMP community string
prinstall scan --subnet 10.0.0.0/16       # explicit subnet instead of auto-detect
prinstall add 10.10.20.16 --force         # reinstall even if duplicate exists

Find printers

prinstall scan throws everything at the wall — SNMP, IPP, TCP port probes on 9100/631/515, and USB enumeration — all in parallel. If a printer is on the subnet and responding to anything, this finds it. Even the ones with SNMP disabled that every other tool misses.

prinstall scan                    # auto-detect subnet from NIC
prinstall scan 10.10.20.0/24     # explicit subnet
prinstall scan --network-only    # skip USB, just hit the network
prinstall scan --usb-only        # just show USB-attached printers

Need to identify a single IP? prinstall id probes one host via SNMP and tells you what it is — model, manufacturer, serial if available.

prinstall id 10.10.20.16

Want to see what Windows already knows about? prinstall list shows every installed queue with its IP address. No admin required.

prinstall list
prinstall list --json

Add a printer

prinstall add is the main event. Point it at an IP and it does the rest — discovers the model, walks a six-tier driver cascade (local store → bundled packs → manufacturer download → Microsoft Update Catalog → SDI Origin → IPP Class Driver fallback), stages the driver, creates the port, and adds the queue. Ten seconds. Done.

prinstall add 10.10.20.16

Want to force a specific driver instead of letting the cascade pick? Use --driver. Want a custom queue name instead of "Brother MFC-L2750DW series"? Use --name.

prinstall add 10.10.20.16 --driver "HP Universal Printing PS"
prinstall add 10.10.20.16 --name "Front Desk Printer"

You can also skip tiers you don't trust. --no-catalog skips the Microsoft Update Catalog. --no-sdi skips SDI Origin. --sdi-fetch lets it download SDI packs on demand instead of requiring a prefetch.

USB printers are a different beast. Windows loves to install them with "Generic / Text Only" and call it a day. --usb swaps the driver on an existing USB queue without recreating it.

prinstall add "HP LaserJet 1320" --usb

Remove a printer

prinstall remove doesn't just delete the queue and walk away. It removes the queue, checks if any other printer is using the driver (if not, removes the driver too), and checks if any other printer is using the port (if not, removes that too). Spooler-lag retry is built in because Windows needs a moment to process its feelings after you delete a printer.

prinstall remove 10.10.20.16
prinstall remove "Brother MFC-L2750DW series"

If you want to keep the driver around for next time, --keep-driver. If you want to keep the port, --keep-port. System drivers like "Microsoft IPP Class Driver" are protected — prinstall won't touch them no matter what.

prinstall remove 10.10.20.16 --keep-driver
prinstall remove 10.10.20.16 --keep-port

Manage drivers

Sometimes you want to stage a driver without installing a printer. Maybe you're pre-loading drivers before a site visit. Maybe you're cleaning up orphaned drivers from printers that left the building three years ago.

prinstall driver show probes a printer and scores every driver in the manifest and local store against it. No admin required — it's read-only.

prinstall driver show 10.10.20.16

prinstall driver add stages a driver from an INF folder, a single INF file, or just a model string. If you give it a model name and there's an unambiguous match in the curated manifest, it auto-picks. If there's ambiguity, it lists candidates and you pick with --driver.

prinstall driver add C:\Drivers\HP\LaserJet
prinstall driver add "Brother MFC-L2750DW"
prinstall driver add "HP Universal Print Driver PS"

prinstall driver remove pulls a driver out of the store. If another printer is using it, it'll tell you which queues are blocking the removal. --force removes the queues first, then the driver.

prinstall driver remove "Brother Laser Type1 Class Driver"
prinstall driver remove "HP Universal" --force

prinstall driver list shows every driver in the store with dates. No admin required.

prinstall driver list
prinstall driver list --json

SDI driver packs

SDI Origin is a community-maintained archive of every printer driver known to humanity. Brother, Canon, Epson, Ricoh — all the vendors that make you download a 200 MB "setup utility" just to get a damn INF file. prinstall can search the archive by hardware ID and auto-install the match.

Every pack's .cat Authenticode signature is verified against Microsoft's certificate chain before install. Unsigned or tampered packs get skipped. Nobody's slipping malware in.

prinstall sdi refresh pulls the latest index from SDIO mirrors. Fast — just metadata, no actual packs.

prinstall sdi prefetch downloads every printer pack in the index. About 1.5 GB, one time. After this, prinstall add can resolve SDI candidates without hitting the network. Great for air-gapped sites.

prinstall sdi verify runs an Authenticode check on every cached .cat file. Reports verified, unsigned, and invalid packs.

prinstall sdi status, list, and clean let you inspect the cache, see what's extracted, and LRU-prune old packs.

prinstall sdi refresh
prinstall sdi prefetch
prinstall sdi verify
prinstall sdi status
prinstall sdi list
prinstall sdi clean

Bootstrap

You can run prinstall from anywhere — it's a single .exe with no dependencies. But if you want it permanently on the machine, prinstall setup install copies itself into C:\ProgramData\prinstall\, adds the directory to Machine PATH, and opens UDP 5353 for mDNS discovery. Idempotent — run it twice, run it ten times, nothing breaks.

prinstall setup install
prinstall setup install --dir D:\Tools\prinstall

prinstall setup uninstall reverses all of it — removes the binary, cleans up PATH, deletes the firewall rule.

prinstall setup uninstall

Interactive TUI

Run prinstall with no arguments in a real terminal and it launches an interactive interface. Currently under construction — the full two-panel layout is being rebuilt. In the meantime, the CLI commands above cover everything.

The binary auto-detects whether it's running in a real terminal or piped through an RMM. If it's piped, it drops to CLI mode automatically — you don't need to set a flag.
