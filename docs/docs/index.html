Global flags

These work on every command.

FlagWhat it does
--jsonMachine-readable JSON output. Pipe it to jq or your RMM.
--verboseStructured install report with discovery, resolution, and install phases broken out.
--forceSkip safety checks. Reinstall duplicate printers, bypass scanner detection, force driver removal.
--community <str>SNMP community string. Default is public.
--subnet <cidr>Explicit subnet for scan. Auto-detected from NIC if omitted.

Discovery

Find every printer on the subnet. Network and USB, in parallel.

prinstall scan [SUBNET]

Multi-method subnet scan — TCP port probe (9100/631/515), IPP, SNMP, and USB enumeration all at once. Auto-detects the subnet from the local NIC if you don't specify one.

prinstall scan                    # auto-detect subnet
prinstall scan 10.10.20.0/24     # explicit subnet
prinstall scan --network-only    # skip USB enumeration
prinstall scan --usb-only        # skip network scan

prinstall id <IP>

Identify a single printer via SNMP. Returns model name, manufacturer, and serial if available.

prinstall id 10.10.20.16

prinstall list

List every printer queue Windows knows about. Shows IP for network-attached queues. No admin required.

prinstall list
prinstall list --json

Install & remove

The core workflow. Add a printer, remove a printer.

prinstall add <IP>

Install a network printer. Discovers the model, walks the six-tier driver cascade, stages the driver, creates the port, and adds the queue. Ten seconds, one command.

prinstall add 10.10.20.16
prinstall add 10.10.20.16 --verbose
prinstall add 10.10.20.16 --driver "HP Universal Printing PS"
prinstall add 10.10.20.16 --name "Front Desk Printer"
FlagWhat it does
--driver <name>Force a specific driver instead of auto-matching.
--name <name>Custom queue name instead of the model string.
--model <str>Override the discovered model string.
--no-catalogSkip the Microsoft Update Catalog tier.
--no-sdiSkip the SDI Origin tier.
--sdi-fetchAllow on-demand SDI pack download (normally requires prefetch).

prinstall add <QUEUE> --usb

Swap the driver on an existing USB printer queue. Windows loves to install USB printers with "Generic / Text Only" — this fixes that without recreating the queue.

prinstall add "HP LaserJet 1320" --usb

prinstall remove <IP|QUEUE>

Remove a printer and clean up after it. Deletes the queue, removes the driver if no other printer uses it, and removes the port if it's orphaned. Spooler-lag retry built in.

prinstall remove 10.10.20.16
prinstall remove "Brother MFC-L2750DW series"
prinstall remove 10.10.20.16 --keep-driver
prinstall remove 10.10.20.16 --keep-port
FlagWhat it does
--keep-driverRemove the queue and port but leave the driver in the store.
--keep-portRemove the queue and driver but leave the TCP/IP port.

Driver management

Stage, list, inspect, and remove drivers independent of any printer.

prinstall driver show <IP>

Show ranked driver match candidates for a printer. Probes the printer, scores every driver in the manifest and local store, and lists them by confidence. No admin required.

prinstall driver show 10.10.20.16

prinstall driver add <PATH|model>

Stage a driver from an INF folder, a single INF file, or a model string. Model-string mode auto-picks from known_matches.toml when unambiguous, or lists candidates for you to pick with --driver. Registers with the print spooler after staging.

prinstall driver add C:\Drivers\HP\LaserJet
prinstall driver add "Brother MFC-L2750DW"
prinstall driver add "HP Universal Print Driver PS"

prinstall driver remove <target>

Remove a driver from the store. Target is an exact name or a fuzzy match. If the driver is in use, tells you which queues block it — --force removes the queues first.

prinstall driver remove "Brother Laser Type1 Class Driver"
prinstall driver remove "HP Universal" --force

prinstall driver list

Every driver in the store, with dates. No admin required.

prinstall driver list
prinstall driver list --json

SDI driver packs

SDI Origin is a community-maintained archive of printer driver packs. prinstall can search it by hardware ID and auto-install the match. Every pack's .cat Authenticode signature is verified against Microsoft's certificate chain before install — unsigned or tampered packs are skipped.

prinstall sdi status

Show cache status — index age, disk usage, pack count.

prinstall sdi refresh

Pull the latest pack index from SDIO mirrors. Fast — just metadata, no pack downloads.

prinstall sdi list

List every cached pack with extraction and verification status.

prinstall sdi prefetch

Download every printer pack in the index (~1.5 GB, one time). After this, prinstall add can resolve SDI candidates without hitting the network.

prinstall sdi clean

LRU-prune the cache. Removes packs that haven't been used recently.

prinstall sdi verify

Authenticode-check every cached .cat file. Reports verified, unsigned, and invalid packs.

prinstall sdi status
prinstall sdi refresh
prinstall sdi prefetch
prinstall sdi verify
prinstall sdi clean

Self-bootstrap

Install prinstall itself onto the machine. Copies the binary, adds it to PATH, and opens the mDNS firewall port for discovery.

prinstall setup install

Copy the running prinstall.exe into C:\ProgramData\prinstall\, add the install dir to Machine PATH, and create the Prinstall (mDNS discovery) firewall rule for UDP 5353. Idempotent — re-running is a no-op.

prinstall setup install
prinstall setup install --dir D:\Tools\prinstall

prinstall setup uninstall

Reverse everything setup install did — remove the binary, clean up PATH, delete the firewall rule.

prinstall setup uninstall

Interactive TUI
